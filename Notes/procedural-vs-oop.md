# Procedural vs Object-Oriented Programming

## Procedural Programming
- Focuses on **functions/procedures**
- Data and functions are separate
- Follows a **top-down approach**
- Suitable for small programs
- Example: **C**

## Object-Oriented Programming (OOP)
- Focuses on **objects and classes**
- Data and functions are combined
- Follows a **bottom-up approach**
- Suitable for large programs
- Examples: **C++, Java, Python**

## Key Difference

| Procedural | OOP |
|---|---|
| Functions | Objects & Classes |
| Top-down | Bottom-up |
| Data + Functions separate | Data + Functions together |
| C | C++, Java, Python |

**Procedural = Functions + Data**

**OOP = Objects + Classes**
